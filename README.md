# Kaleidoscope II Arabic translation editor for Windows x64

A Windows x64 local browser editor for building an Arabic patch for *Kaleidoscope of Phantom Prison II* (title ID `0100451020714000`). The editor stores translations in a separate project directory and builds a Suyu LayeredFS `patch.rom`. It does not translate the game automatically or include game files.

## Windows setup

1. Install [Python 3.12.10 for Windows x64](https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe). In its installer, select **Add python.exe to PATH** and **Python launcher**. Install [RubyInstaller x64](https://rubyinstaller.org/downloads/) with `ruby.exe` on `PATH`, and the [Microsoft Visual C++ x64 runtime](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist). Install Suyu separately to run the patch. These are the only system programs the setup script cannot install for you.
2. Download or clone this repository and extract the ZIP if you downloaded one. In the extracted `Kaleido2-Arabic-Editor` folder, **double-click `setup.cmd`**. Do not open Python to run this file; it is a Windows command file. The setup window stays open at the end so you can read any error. A successful run creates a `.venv` folder beside `setup.cmd`, installs the pinned Python packages, downloads the official Windows `sdu.exe` and `EnterExtractor.exe` releases, and downloads the two public patch compiler sources. Each tool or source archive is checked against a pinned SHA-256 hash. The Noto Sans Arabic font is already bundled under its [Open Font License](assets/OFL-NotoSansArabic.txt).
3. `setup.cmd` creates `config.local.json`. Set **`data_rom`** to the actual path of `data.rom` extracted from your own game. `C:/Kaleido2/game/data.rom` is only an example. Use forward slashes in JSON paths. The editor extracts its original story and system fonts from that ROM when building, so separate `.fnt` files are optional. If you already extracted them, you can set `original_story_font` and `original_system_font` to their paths. The bundled tools, compiler sources, and Arabic font work with the supplied defaults. If Ruby is not on `PATH`, set `ruby_bin` to its full `ruby.exe` path.
4. Run **`run.cmd`** and open the printed address (`http://127.0.0.1:8778/` by default). `run.cmd 8780` chooses another port. The server binds to your own computer only.

If `.venv` does not appear, read the `ERROR` line in the setup window. The most common cause is that Python 3.12 x64 is missing or a different Python version is on `PATH`. Install Python 3.12 x64, then run `setup.cmd` again. If setup still stops, send the complete error shown in the window.

`project_dir` defaults to `./project` beside the editor; keep this folder to preserve your translations and image edits. Relative paths in `config.local.json` are resolved from the config file's folder. `config.local.json`, downloaded tools/sources, game files, and generated patches are ignored by Git. You can replace the bundled font by setting an optional `arabic_font_path` in the config.

If an older `config.local.json` still contains example paths for `original_story_font` or `original_system_font`, you can remove those two entries. The editor uses `data_rom` to extract both fonts at build time. A missing `C:/Kaleido2/game/...` path means that example location has not been changed to the location of your own extracted game file.

The default Suyu mod path is `%APPDATA%/suyu/load`. If you use a portable Suyu installation, right-click the game in Suyu and choose **Open Mod Data Location** to find the correct location, then set `suyu_load_dir` to its `load` folder. Close the game before installing a patch so the old file is not locked.

If **Extract all images** reports that it cannot find an ASCII-only temporary directory, create a writable folder such as `C:/KaleidoTemp` and set `KALEIDO_ASCII_TEMP_DIR` to that folder before starting `run.cmd`. The Windows EnterExtractor binary requires ASCII paths for its input and output arguments; the editor stages conversion files there when needed.

## Translate and build

The catalog covers **5,926 dialogue IDs**, **23 speaker names**, **70 editable UI strings**, **29 read-only gallery asset keys**, **372 PNG previews** after extracting all images (181 from 14 menu/UI atlases and 191 standalone pictures), and **2 videos**. The image count is zero in a new project until you click **Extract all images**. Translation coverage numbers count saved edits, not reviewed quality.

1. **Dialogue:** Search or filter the script, edit the Arabic body, and save each entry. The editor shows the Japanese source, speaker, voice reference, and an immediate RTL text preview. Keep inline commands such as `@r` where they are needed; the exporter validates required control commands and line IDs. Translate the whole dialogue line before exporting it; mixing Arabic with untranslated Japanese in one line produces a build error. Translate speaker labels once in the **Speaker** field beside a line to apply that name across its lines. Empty speaker labels are narration.
2. **UI strings:** Edit save labels, choice text, and BGM display titles. The 29 gallery asset keys are shown for context and cannot be changed because they identify assets. Baked menu/gallery text belongs in the image editor.
3. **Images:** Extract all game images, browse thumbnails, then add Arabic text in the canvas. Use a solid cover rectangle where needed, and **Save image** to store the rendered PNG. You can also upload an externally edited PNG. Keep original dimensions, alpha, and button states. The builder includes only changed images. See [docs/images.md](docs/images.md) for the image pipeline and limits.
4. **Videos:** Preview `movie/op2.mp4` and `movie/ed.mp4`; edit frames and credits in a video editor, then upload replacement MP4s. The browser does not edit video frames.
5. **Export:** Click **Build patch**. The patch is written to `project_dir/build/patch.rom`; details and errors are in `project_dir/build/build.log`. Then click **Install to Suyu**. This copies the patch to `<suyu_load_dir>/0100451020714000/<mod_name>/romfs/patch.rom`. The installer rejects another active `patch.rom` mod for this title to avoid conflicting overrides. Close and restart the game in Suyu after installation.

Edits and image previews update immediately **in the browser**. The running game does **not** hot reload: build, install, and restart it to see changes in Suyu. Keep the project directory to continue translating; its JSON edit files are separate from the original game and patch sources.

## Development verification

The Windows GitHub Actions job checks the pinned setup downloads, Python startup, Arabic font generation, Unicode paths, and a synthetic patch build and install. A separate development smoke build using the real game assets produced a `ROM2` patch. In Linux Suyu, dialogue ID `00007` showed the rightmost Arabic word first, the next word to its left, and then the complete correctly ordered line. This verifies word-by-word right-to-left reveal for that sample. A complete build and in-game review with those assets on Windows is still needed. Translators should inspect each edited screen in Suyu as they work.

## Limits to review in game

- Arabic text uses generated private-use glyphs in replacement FNT6 fonts because the original fonts have no Arabic glyphs. Each baked word appears at once; letters do not animate separately. The exporter checks character coverage and preserved commands. Ruby-style pronunciation annotations (`@b`, `@<`, `@>`) must be flattened into ordinary text in translated lines. Long lines, unusual control tags, and the full game's text reveal and layout still require visual review. Position-specific glyphs may consume many codepoints and font descriptors as translation grows; a full-game capacity test has not been completed.
- A source inventory found menus and manual text baked into texture images. The editor exposes TXA/PIC PNGs; character bustups and transition masks are outside this image importer. Video text needs external editing. No dubbing or audio editing is provided.
- Dynamic labels generated by the game engine may remain untranslated. The catalog is an inventory of the inspected script and assets, not a guarantee that every screen is localized. Check choices, saves, menus, video, and long lines in Suyu as translations are added.
- This tool expects an already extracted, user-owned `data.rom`. It does not acquire a game, extract an XCI, or distribute copyrighted game assets, keys, original images, audio, or video.
